# Equipo Vio Coders

## Descripción

**Sonido Vivo** es un sistema web integral diseñado para modernizar las operaciones de la **ficticia** tienda de instrumentos musicales y equipos de sonido ubicados en Viña del Mar, Región de Valparaíso. El propósito del proyecto es aplicar los conocimientos de la asignatura, que tiene como núcleo usar React y sus librerias, como solución para centralizar y agilizar las operaciones de la tienda en una aplicación.

## Estructura del proyecto

El sistema seguirá el patrón de diseño **Atomic Design**, que modulariza cada elemento de la aplicación jerarquicamente, para facilitar la reutilización y escalamiento del proyecto.

```
src/
├── components/
│   ├── atoms/
│   ├── molecules/
│   ├── organisms/
│   └── templates/
├── pages/
├── data/
├── services/
├── context/
└── utils/
```

## Ejecución

Para ejecutar el sistema debe tener instalado Node y npm en su equipo, puede usar nvm o descargarlo de un proveedor confiable.

Luego clone el repositorio con `git clone`, entre al directorio de Sonido-Vivo y ejecute `npm install`

Una vez instaladas las dependencias ejecute `npm run dev`

Ya iniciado, Vite mostrará en la terminal la dirección local donde se encuentra disponible la aplicación. Por defecto, puede accederse desde:

`http://localhost:5173`

Para detener el servidor de desarrollo, presione:

`Ctrl + C`

### Requisitos
- Node.js 24.x o superior
- npm 11.x o superior
- Navegador web moderno (Chrome, Firefox, Edge, etc.)
